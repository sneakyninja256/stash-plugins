## Plugin List

### Audio Tab

Adds a new tab for audio-only scenes to the main menu.

![Audio tab](images/audioTab/audioTab.png?raw=true "Audio tab")

> Note: Stash does not currently (v0.28) support playing audio-only files.
> You will need an audio support plugin such as [StashAudioPlayer](https://docs.stashapp.cc/plugins/list/#stashaudioplayer).
